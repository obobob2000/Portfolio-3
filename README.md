# olivierbuetz.com – Portfolio

Statische Seite (HTML, CSS, JavaScript). Kein Build-Schritt nötig.

## Inhalt
- `index.html` – die Seite
- `kadenz-prototyp.html` – der Kadenz-Prototyp; läuft in der iPhone-Kachel und im Overlay von selbst ab
- `assets/` – alle Bilder
- `favicon.svg`, `apple-touch-icon.png` – Icons
- `og-image.jpg` – Vorschaubild für Link-Vorschauen
- `vercel.json`, `robots.txt`, `sitemap.xml` – Einstellungen für Vercel und Suchmaschinen

## Seite aktualisieren
1. Repo auf github.com öffnen.
2. **Add file → Upload files**.
3. Alle Dateien aus diesem Ordner hineinziehen (auch den Ordner `assets`).
4. **Commit changes** klicken.

Vercel ist mit dem Repo verbunden und stellt die neue Version nach dem Commit von selbst live.

## Schrift
Die Seite nutzt „Akkurat LL“, falls auf dem Gerät installiert, sonst Hanken Grotesk (Google Fonts).
Der Kadenz-Prototyp lädt Geist und Archivo über Google Fonts.
